Espace administration

Pour ajouter ou modifier vos photos avant/après, entrez votre code d'accès GitHub. Il reste dans ce navigateur et n'est envoyé qu'à GitHub.

Comment obtenir mon code d'accès ?
  1. Connectez-vous à GitHub avec le compte propriétaire du site, puis ouvrez la création d'un jeton d'accès.
  2. Donnez-lui un nom (par exemple « Rénov'Habitat admin ») et choisissez une durée de validité.
  3. Repository access : « Only select repositories », puis le dépôt du site (Renov-Habitat).
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Cliquez sur « Generate token », copiez le code (il commence par github_pat_) et collez-le ci-dessus. GitHub ne l'affiche qu'une seule fois.

Ne partagez jamais ce code : il permet de modifier le site. Une fois expiré, il suffit d'en générer un nouveau.
